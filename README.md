# 規章規範之智慧檢索增強生成（Hybrid RAG POC 實作筆記）

> **免責聲明**：本專案為個人針對高合規性知識庫檢索優化之技術可行性驗證（POC）。所有展示資料、測試情境與規章文本均為**開源虛構/隨機合成資料（Synthetic Mock Data）**，不含任何特定金融機構或企業之內部機密資訊。

---

## 1. 核心痛點與解題背景

在高合規性作業手冊與內控準則中，文本充滿**特定條文代號（如 OP-RISK-302）、表格代碼與嚴格數值門檻（如通報金額、審批級距）**。

* **條號語意稀釋（Tokenizer 盲區）**：通用向量模型（Bi-Encoder）遇到壓縮度極高之代碼時，易拆分為碎片子詞，導致特定代碼檢索命中率低下。
* **數值門檻邊界模糊**：在純向量空間中，「3,000 萬元」與「1,000 萬元」之語意餘弦相似度極高，純語意檢索難以辨識臨界數值差異。
* **假性高分誘發模型幻覺**：餘弦相似度僅代表相對方向，庫外無效提問（如借用設備流程）常因通用詞彙取得假性高分，導致後續生成硬塞錯誤條文，衍生合規風險。

---

## 2. 迭代歷程與架構演進

在 POC 階段針對模擬規範進行三次架構驗證與迭代：

| 迭代版本 | 採用架構 | 核心表現 | 淘汰原因 / 局限性 |
| :--- | :--- | :--- | :--- |
| **Phase 1: Baseline** | 純 Dense 向量檢索<br>(all-MiniLM / BGE) | 語意泛化佳，能理解同仁口語提問 | **條號精確命中率僅約 50%**，常因相似度模糊召回錯誤條號或權限層級 |
| **Phase 2: 關鍵字補強** | 純 Sparse 檢索<br>(BM25) | 條號與固定術語命中率達 85% 以上，檢索極快 (<2ms) | **完全喪失同義詞理解**，遇前線口語化事件描述時常因字面不符而完全漏檢 |
| **Phase 3: 雙路混合架構** | **BM25 + Dense + RRF + Cross-Encoder** | **條號與情境意圖綜合命中率達 98%** | 增加約 30ms 重排運算耗時，但在高合規代價場景下完全符合 ROI |

---

## 3. 現階段核心技術抉擇

1. **倒數排名融合（RRF）取代分數絕對值加權**：  
   BM25 分數與 Cosine 餘弦相似度數值尺度與分布不同，手動設定加權超參數極易過擬合；採用 **RRF（Reciprocal Rank Fusion）** 純依排名權重融合，具備無須校準尺度（Scale-invariant）之穩定性。
2. **全注意力機制（Cross-Encoder）精準捕捉數值條件**：  
   在第二階段重排中，利用 Cross-Encoder 針對 `[Query, Document]` 進行 Cross-Attention 交叉計算，克服 Bi-Encoder 分開編碼時遺失的細部條件交互資訊（如多重但書與金額級距）。
3. **抗幻覺門檻截斷防禦（Guardrails）**：  
   監控重排後之 Logits 得分，若最佳候選段落相關度低於安全門檻，系統強制判定「查無對應作業規範」並中斷檢索，嚴禁模型任意生成回答。
